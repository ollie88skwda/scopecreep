ScopeCreep / Notary
Privacy policy

What we collect: nothing.

Last updated 2026-05-24 · Applies to ScopeCreep Notary Chrome extension v0.4.0+

The short version

ScopeCreep Notary runs entirely in your browser. It does not send your messages, SOW, hourly rate, name, settings, stats, or anything else to any server. There is no analytics, no telemetry, no third-party scripts. All data lives in your browser's local storage on your device and stays there until you uninstall the extension or clear the storage manually.

Data we collect

None. We operate no backend service, run no analytics, ship no third-party scripts, and have no business model that depends on collecting your data.

Data the extension stores (on your device only)

The extension uses Chrome's chrome.storage.local API to persist the following on your device. None of this leaves the browser:

  • Your SOW / project scope text — the contract or scope summary you paste into Settings for reference context
  • Your hourly rate — used to fill in the change-order email draft
  • Your name and an optional default client name — used in the draft greeting and signature
  • Your Slack display name — used to skip your own messages so the extension only flags incoming client asks
  • Your selected email template — which of the 4 tone variants you last picked
  • Your stats counters — how many messages flagged / dismissed / drafts copied since you started using the extension
  • The most recent flagged message context — quoted text + matched phrases, so the popup can show the panel state when you reopen it
  • Recent errors — a ring buffer of up to 20 internal errors with timestamp + brief context, so you can see if the extension breaks. Cleared via the Settings → Clear errors button.

If you uninstall the extension, all of the above is deleted by Chrome.

Data the extension reads (in-page, transiently)

The extension's content script runs on app.slack.com pages only. It reads the text of visible Slack messages in your browser to check them against the scope-expansion lexicon. This message text is never sent anywhere — not to our servers (we have none), not to any third party, not to Slack beyond what your browser was already doing.

When the extension detects a scope-expansion phrase, it adds a small badge to the message in the page DOM. The matched phrase ID and message text are passed only to the extension's own popup (when you click the badge) for the change-order draft. They are not transmitted off your device.

Permissions and why

activeTab

So the extension can read the currently-focused Slack tab when you click the toolbar icon. Required to surface flagged messages in the popup.

storage

So the extension can persist your settings + stats + recent-flag context across sessions via chrome.storage.local. Data never leaves your device.

scripting

So the content script can inject the badge styles + click handlers into Slack pages.

host_permissions: https://app.slack.com/*

So the content script runs only on Slack — never on any other site you visit.

Third-party services

None. The extension has zero network connections to any external service. It does not:

  • Send data to any analytics provider (no Google Analytics, no Mixpanel, no Segment, etc.)
  • Load any third-party scripts
  • Use any AI / LLM APIs at runtime — scope-expansion detection is a deterministic local lexicon match
  • Phone home for updates, telemetry, or "anonymous usage data"

Data we do not have access to

We have no servers. We have no database. We cannot see your messages, settings, or stats even if we wanted to. This is enforced by the extension's architecture — there is no code path that transmits your data anywhere.

Children's privacy

The extension is intended for use by professionals (freelancers and consultants) managing client work. It is not directed at children under 13 and does not knowingly collect personal information from children.

Changes to this policy

If the privacy posture changes (e.g. we add optional cloud sync as a Pro-tier feature), this page will be updated with a new "Last updated" date and a clear changelog entry. Material changes will be flagged in the extension popup before they take effect.

Open source
